# Unique Features Classification — chezmoi dotfiles repo

Worktree: `../chezmoi-scan` (branch `master`, isolated from `feat/ai-assist-phase-c1`).
Scope: features beyond standard tool config (bat/atuin/bottom/git/gnupg/gh/glow/tealdeer/mise/npm/homebrew/espanso, LazyVim defaults, basic terminal themes & keymaps are excluded).

## A. Terminal / multiplexer cross-tool integration stack
The central theme: Zellij as the multiplexer, hosted by WezTerm or Ghostty, with hand-built bridges so the host terminal, the multiplexer, nvim, yazi, and macOS all cooperate.

1. **SSH clipboard bridge (host↔remote nvim)** — `nvim/lua/config/options.lua`. On SSH, copy uses write-only OSC 52 (yanks ride up WezTerm to the Mac clipboard with no terminal query → no hang); paste reads the host clipboard back through a **reverse SSH tunnel** served by a launchd `clipboard-bridge` socat agent (`pbpaste` → `~/.clipboard-bridge.sock` → `nc -U`). Falls back to unnamed register when the tunnel's absent. *This is the exact feature you cited.* Gated to SSH so local nvim keeps `pbcopy`. Substantial.
2. **OSC 52 origin-relative clipboard (Zellij)** — `zellij/config.kdl.tmpl`. `copy_command` intentionally unset; Zellij re-emits OSC 52 to the focused client's terminal, so copy is origin-relative (local→local, over SSH→laptop). Substantial rationale.
3. **WezTerm `file://` link → Zellij session dispatcher** — `wezterm.lua` + `zellij/scripts/zellij-open` + `lib/zellij-session.zsh`. Clicked links open dirs in a Yazi tab, images in a sized floating preview pane, text/code in an nvim tab (CWD=git root), by resolving the clicked pane's Zellij client → session. Substantial.
4. **Workspace-rename side-channel** — `wezterm.lua`. Alt+Enter fullscreen and quick-launch window-focus ride state in the workspace *name* (`__TOGGLE_FULLSCREEN__`, `__QL_FOCUS__=<id>`) via `mux.rename_workspace`, no osascript / sidecar file. Substantial.
5. **Fullscreen-state mirror file** — `wezterm.lua` → `~/.local/state/wezterm/fullscreen_state`. Atomic, write-on-change, polled by the zj-hud status bar to reveal its chrome only when WezTerm's tab bar is hidden in fullscreen. Substantial.
6. **Zellij-chord passthrough keybindings + mouse-reporting-aware paste/link** — `wezterm.lua`. Disables WezTerm defaults that swallow Ctrl+Shift+hjkl/arrows so vim-navigator resize reaches Zellij; rebinds Cmd+keys to `Alt+w …` chords with 20ms stagger; middle-click paste / Cmd+click link open use `mouse_reporting = true` so they fire while Zellij captures the mouse. Substantial.
7. **Nested-session-aware picker split** — `wezterm.lua` + `nested-session-check`. Cmd+Shift+P detects nested/passthrough Zellij and sends raw kitty CSI-u `\x1b[32;7u` (Ctrl+Alt+Space) to summon the LOCAL workspace picker (SendKey mis-encodes that chord → NUL); outside sends normal chord; Cmd+Shift+Alt+P forwards to REMOTE Zellij's picker. Substantial.
8. **SSH agent anti-hijack** — `wezterm.lua`. `mux_enable_ssh_agent = false` so detached shells keep the launchd/system SSH agent that 1Password registers with, instead of a stale mux symlink. Snippet.
9. **Curated multi-font fallback chain with emoji-presentation overrides** — `wezterm.lua`. Duplicated Apple Color Emoji with `assume_emoji_presentation = false` routes text-default emoji (♻ ✏) to color glyphs; tightly coupled to the custom Nerd Font build's cmap stripping. Substantial.
10. **WezTerm config-reload deduping + Hammerspoon OSD notify** — `wezterm.lua`. Snapshots config bytes in `wezterm.GLOBAL` to fire exactly one OSD reload notification across multi-window/multi-eval reloads. Substantial.
11. **Ghostty emoji codepoint-map + ZWJ/VS16 forwarding** — `ghostty/config`. Ports the WezTerm font chain via `font-codepoint-map` for text-default symbol ranges, with documented Zellij-0.44.3 Cf-codepoint-drop caveats (refs upstream PRs #4800/#4920). Substantial.
12. **Ghostty performable keybinds + chord forwarding** — `ghostty/config`. `performable:` prefix excludes overrides from the macOS menu; `arrow_up/down` (physical) override Ghostty's super+arrow defaults; Cmd+F→`ESC /` for Zellij entersearch; Cmd+Shift+Up/Down→leader scroll-mode `p`/`n` (zj-promptjump). Substantial.
13. **Cross-terminal fullscreen toggle from inside Zellij** — `zellij/scripts/terminal-toggle-fullscreen` + `config.kdl.tmpl` Alt+Enter bind with `when fzf: $source`. Detects WezTerm (workspace-rename side-channel, no osascript) vs Ghostty (osascript AXFullScreen / hyprctl/swaymsg/wmctrl) vs SSH; forwards the raw key to the pane when fzf is in the process tree. Substantial.
14. **Session→WezTerm-window live resolver** — `zellij/scripts/lib/zellij-session.zsh`. `resolve_session <client_pid>` inspects the client's unix-domain sockets to find which Zellij session it's attached to (tracks live session switches with no `--session` arg); `zellij_wezterm_sessions` enumerates every WezTerm pane running a Zellij client → `<session>\t<window_id>\t<pane_id>`. Substantial.
15. **zj-hud custom status bar / which-key / visual-search (same wasm, 3 roles)** — `zellij/layouts/default.kdl.tmpl`. A custom fork of zj-hud loaded via `file:`, spawned per-tab as parked 1×1 floating panes revealed by mode; `role "whichkey"` / `role "search"` / `role "rename"`. Bar self-detects fullscreen via the WezTerm mirror file. Substantial.
16. **zj-promptjump** — custom Zellij wasm plugin (`~/Projects/apps/zellij/zj-prompt-jumper`) scanning scrollback for the p10k prompt prefix to re-align the viewport prompt-by-prompt; works around Ghostty's native `jump_to_prompt` being unusable through Zellij's VTE. Substantial.
17. **visual-search dialog via parked role instance** — `config.kdl.tmpl` `Alt /`→EnterSearch reveals the `role "search"` floating instance; search-option toggles route through `MessagePlugin` so the bar's hint glyphs stay in sync (native `SearchToggleOption` isn't observable by a plugin). Substantial.
18. **which-key panel with custom binding labels + mode trail** — `layouts/default.kdl.tmpl` `which_key {}` block + `config.kdl.tmpl` panel controls (Alt+./Ctrl+d/Ctrl+u/Backspace). Backspace steps back along the mode trail; the search excursion is frozen out of the trail. Substantial.
19. **Plugin permission pre-grant** — `.chezmoiscripts/run_after_45-grant-zellij-plugin-permissions.sh.tmpl`. Pre-populates Zellij's `permissions.kdl` cache granting all 17 permission variants for every managed plugin path; works around upstream #4982 (headless plugins can't be granted interactively → silently fail over SSH/nested). Substantial.
20. **ensure-plugins self-managed wasm fetcher** — `zellij/executable_ensure-plugins.tmpl`. Fetches plugin wasms itself (sequential, redirect-following, retried, magic-validated `\0asm`) into `~/.local/share/zellij/plugins/`, bypassing Zellij's http downloader which caches transient CDN errors (404/504 HTML) as the wasm and never retries. Substantial.
21. **zellij-modal shared floating-dialog scaffolding** — `zellij/scripts/zellij-modal`. Single entry point for all floating modals (glyph/gitmoji/quick-launch/quit): Catppuccin title block, discovers the originating tiled pane, `--inject` captures target stdout and `write-chars` injects back, `--capture FILE` writes to a FIFO the spawner blocks on. Substantial.
22. **zj::pick — floating-pane fzf picker for the shell stdlib** — `lib/zellij.zsh`. Drop-in for `pick::start` that floats the picker in a Zellij pane when in a session, falls back inline otherwise; stages stdin to a temp file (float child can't read the pipe), spawns via `zellij-modal --capture FIFO`. Substantial.
23. **Headless context-keys plugin actions (flash-free)** — `config.kdl.tmpl` (Alt+Enter, `Y`, Alt+y, `,`) + `copy-pwd`/`edit-terminal-config`/`terminal-toggle-fullscreen`. Dispatched into the headless `zj-context-keys` plugin's `run` action (zero pane, zero flash); copy-pwd resolves focused pane cwd via `lsof` on the plugin-supplied `{pid}`. Substantial.
24. **Nested-Zellij passthrough workspaces** — `zellij/scripts/lib/dispatch.zsh` + `quick-launch-schema.md` + `wezterm.lua`. `nested_zellij: true` workspaces launch a generated bar-less layout with `clear-defaults=true` keybinds so every key except Ctrl+Alt+Space passes verbatim to the inner Zellij (Locked mode unreachable for custom-layout sessions in 0.44); session registered to `~/.cache/quick-launch/nested-sessions` so WezTerm's nested-check can remap the picker. Substantial.
25. **image-protocol-support.zsh** — `lib/image-protocol-support.zsh`. Two-step resolver: accumulate host-native protocols from `TERM_PROGRAM`/`ITERM_SESSION_ID`/`LC_TERMINAL`, then constrain through Zellij (only Sixel survives the multiplexer). Used by `preview` to pick Kitty/iTerm2/Sixel. Substantial.

## B. NVim custom systems (LazyVim-based)
26. **Chezmoi source redirect + debounced auto-apply** — `nvim/lua/config/autocmds.lua`. `BufReadPre` transparently swaps a chezmoi-managed destination for its source (`.tmpl`, `symlink_*`) so edits hit the repo; runs `chezmoi-reverse --no-merge` first to reconcile external drift; `BufWritePost` schedules a 5s debounced scoped `chezmoi apply --force` (coalesces AutoSave); `VimLeavePre` flushes. `:ChezmoiRefresh`/`:ChezmoiApplyNow`/`<leader>uM`. Substantial.
27. **Chezmoi/go-template compound filetype system** — `nvim/lua/config/options.lua` + `after/queries/gotmpl/injections.scm`. `.json.tmpl`→`json.gotmpl`, `Brewfile.tmpl`→`ruby.gotmpl`, etc.; custom `inject-inner-ft!` treesitter directive strips the `.gotmpl` suffix and injects the inner language into the gotmpl parser's `(text)` nodes — proper inner-language highlighting/LSP/folds under `{{…}}`. Substantial.
28. **Unicode code-point escape hints + conversion** — `nvim/lua/utils/unicode.lua` + keymaps + autocmds. Recognizes `\u{HEX}`/`U+HEX`/`\uHHHH`; `<leader>cu` rewrites escapes to glyphs in place; inline-hint decoration via **persistent extmarks** (ephemeral virt_text doesn't render) showing the resolved glyph as dimmed virtual text, toggleable `<leader>uU`. No built-in nvim equivalent. Substantial.
29. **Harper grammar/spell + shared dictionary auto-pairing** — `nvim/lua/plugins/harper.lua`. `harper-ls` unified with vim spell via a shared `spell/en.utf-8.add` (chezmoi `create_`-prefixed so apply never reverts); `uv.new_fs_event` watcher auto-pairs base↔possessive (`Zellij`↔`Zellij's`), runs `mkspell!`, reloads `spelllang` per window, pings Harper `workspace/didChangeConfiguration`. Overrides `z=`/`zg`. Substantial.
30. **Markdown list-continuation wrap alignment** — `nvim/lua/utils/markdown_format.lua` + `after/ftplugin/markdown.lua`. Fixes vim's `formatlistpat` `n`-flag only indenting the first wrapped continuation line; extends the pattern so each continuation line propagates indent; custom `formatexpr` re-wraps list paragraphs for `gq`/`gw` (with `gw`→`gq` remap); treesitter `<C-CR>` inserts the next list/quote item with the correct marker. Substantial.
31. **Smart-comment-wrap local plugin** — `nvim/local-plugins/smart-comment-wrap/` (self-authored, unpublished). Treesitter-detects standalone vs trailing comments, wraps only standalone blocks at a custom `comments_width` editorconfig property (custom `editorconfig.properties` handler), dynamic `textwidth` switching, excludes prose. Substantial.
32. **Custom doom-modeline lualine theme + components** — `nvim/lua/lualine/`. Theme dynamically extracts colors from the active colorscheme via `nvim_get_hl` (no hardcoded palette); custom components `dynamic-fqn` (project-root-aware path abbreviation, cached + autocmd-invalidated, max 50% statusline area), `special-title` (priority-based context titles for Help/Trouble/Snacks/OpenCode/terminal/quickfix), `opencode` (AI status). Substantial.
33. **Blink.cmp smart Tab/Escape actions + nightly-toolchain build** — `nvim/lua/plugins/coding.lua`. Session-state `last_direction` so Escape only cancels after you've navigated; Smart Tab auto-accepts on single completion, prefers exact snippet-label match, else cycles; custom `build` recreates `mise exec rust@nightly` so blink builds against the right toolchain. Small-medium.
34. **Custom build integration: zsh treesitter parser + kdl-lsp + blink.lib** — `nvim/lua/plugins/coding.lua`. `local_parsers` entry for a dedicated tree-sitter-zsh grammar (not in nvim-treesitter's registry) + `zsh -n` linter + `shfmt` for zsh; inline `kdl_lsp` (provisioned by `system-package cargo sync`); restricts `gopls` filetypes so it doesn't crash on `*.tmpl` gotmpl files; adds `blink.lib` dep. Medium.
35. **OpenCode AI integration + terminal keymaps** — `nvim/lua/plugins/ai.lua`. `@this` context-prefix keymaps (`<leader>aa`, visual `gaa`/`gao`/`gax`, operator `<leader>al`), `<leader>ao` auto-focus toggle, buffer-local terminal keymaps (`<S-C-b/f/g>`) scoped to `opencode_terminal` via `TermOpen`. Medium.
36. **Misc custom keymaps** — `nvim/lua/config/keymaps.lua`. `;`/`:` swap; Ctrl+; / Ctrl+Alt+; quick `:lua`/`:=`; `gV` reselect last paste/change (reconstructs visual mode from `[`/`]` marks + register type); `gX` jump to treesitter-context sticky-scroll start. Small.
37. **Yazi Lua types autocmd + NumberToggle** — `nvim/lua/config/autocmds.lua`. Adds `types.yazi` to `lua_ls` workspace only when editing `~/.config/yazi/**/*.lua`; relative/absolute number toggle skipping special buffers. Small.

## D. The `pick::` picker framework + symbols DB (flagship subsystem)
49. **`pick::` engine** — `lib/pick-common.zsh` (38K) + `pick.jq` + `libexec/pick-list`. From-scratch fzf picker framework standardizing every fuzzy picker: baked Catppuccin palette/border/hints, `--print-query`/`--expect` key splitting, cancel→130 path. Wire contract: `<visible>\x1f<tail[0]>\x1e<tail[1]>…` (US splits display from hidden plain-text tail, RS splits tail fields; ANSI never leaks to stdout). Features: two-tier **recency** (file-based `--cache-usage` rank-merge for non-DB pickers; SQLite `last_used` stamp via `--on-items-picked` for DB pickers), **resume** (`--cache-state`+`--resume` replay query through `fzf --filter` to recompute cursor index), **selector mode** (`--selector`/`--selector-shortcuts` 1-9 digit rows/`--selector-nav`), **insert-without-dismiss** (`--key-background` FIFO broker bridging fzf's `execute-silent` child-shell back to an in-process zsh hook that injects into the originating Zellij pane or clipboard), **multi-output keys** (`--key-output ctrl-n:field:2`, `--multi`, `--copy-only`). Substantial — single largest custom subsystem.
50. **Symbols DB pipeline** — `custom-builds/nerd-fonts/symbols-db/build-symbols-db.py` (46K) + `lib/pick-symbols-common.zsh` + `libexec/pick-glyph`/`pick-gitmoji` + hook `run_onchange_after_60-symbols-db.sh.tmpl`. Pure-stdlib Python builder producing one flat SQLite `symbols` table (~29k rows) merging the custom Nerd Font, FA7, Unicode stdlib, gemoji, iamcal emoji-data, gitmoji, with faceted metadata (primary shortcode by priority `gitmoji>github>slack>emoticon`, extra_shortcodes, keywords, tags). **Host-specific renderability probe** using `wezterm ls-fonts --text` as oracle (drops `.notdef` tofu), CoreText fallback. `pick-glyph` streams from SQLite with raw-glyph / `:shortcode:` / `\u{HEX}` output modes + Alt- twins for insert-without-dismiss. Substantial.
51. **Glyph + Gitmoji Zellij modal pickers** — `zellij/scripts/pick-glyph-zellij`, `pick-gitmoji-zellij` + `config.kdl.tmpl` (Ctrl+Shift+u/g). Floating pinned modals exec the libexec pickers; `zellij-modal` captures stdout and `write-chars` injects into the originating pane; leader `U`/`G` resume with query + cursor restored. Substantial.
52. **Quick-launch (Zellij panes/tabs/workspaces dispatcher)** — `zellij/scripts/quick-launch` + `lib/{config,command,dispatch}.zsh` + `quick-launch/default.yaml.tmpl` + `launch.d/`. CLI port of `quicklaunch.wezterm`: YAML/JSON/TOML targets (managed `default.yaml` + host-local `launch.d/` merged+deduped by id) define workspaces/tabs/panes with Shell/Edit/Run/Remote actions, python_venv/mise_env activation, focus-or-create dispatch; apply-time gating bakes out machine-specific workspaces by project-dir existence; generates Zellij layouts via `action new-tab`/`new-pane`; picker built on `pick::start` with `--cache-usage` recency; Alt+Enter emits `@window:<id>` to open in a separate OS window. Substantial.

## E. AI agent harnesses
53. **`ai-assist` terminal AI assistant harness** — `bin/ai-assist` + `ai-assist-{claude,cursor,pi,test}` + `lib/assist-agent-common.zsh` + `libexec/ai-assist-{summon,popup,render,action-broker}` + widget `ai-assist-trigger` (bound Ctrl+Alt+A). Dispatcher discovers sibling workers via a `--probe` contract, selects by explicit arg→env→session pin→sole→picker; harness pinned per Zellij session (`$XDG_STATE_HOME/ai-assist/sessions/<name>/harness`). Shared engine captures context via Atuin (`atuin history last`) + `zellij action dump-screen` slicing (awk, capped), detects SSH, resolves git root/branch, builds a system prompt + per-project KB (`$XDG_DATA_HOME/ai-assist/projects/<sha1>/knowledge.md`), spawns the agent in a docked right-side Zellij pane wrapped by `ai-assist-render` (title + spinner + glow). Substantial.
54. **`ai-commit` AI-driven atomic commit planner** — `bin/ai-commit` + `ai-commit-{claude,cursor,pi}` + `lib/commit-agent-common.zsh`. Dispatcher mirrors `ai-assist`'s probe/pick; workers ask a headless LLM (Claude `--print --permission-mode bypassPermissions`, or `pi --print --no-session`) to read the diff and emit a JSON plan `{commits:[{files,message}]}` to a tempfile — the agent NEVER runs git. Shared engine: braille spinner w/ elapsed, plan summary, `--dry-run`, `--no-commit` (opens `$EDITOR` per commit, `prompt::confirm` to commit), stages+commits one group at a time; cached plans under `.git`, `--replan` forces refresh; clean unstage on abort. Substantial.

## F. Secrets & onboarding system (leak-safe, public repo)
55. **Slot-based dual-backend secrets + onboarding** — `bin/system-secrets` + `system-onboard` + `lib/system-secrets-common.zsh` (24K) + `zsh/private_secrets.d/private_slot-*.sh.tmpl` + `.chezmoidata/secrets.yaml` + `secrets/<slot>.sops.sh` + `.sops.yaml` + `.leak-patterns`. Committed manifest declares env var NAMES + prompts + `requiredFor` profiles — no values. Opaque slot ids (`slot-<6hex>`, never alias/hostname). Loose operator map `~/.config/chezmoi/onboard-map.yaml` (0600) maps slot→{alias,profile,kind,recipient}. Two materialization paths: **human** = 1Password `op read` refs resolved at apply with an `op-cache-v1` content-hash cache (skip re-resolution unless `CHEZMOI_REFRESH_SECRETS=1`); **headless** = SOPS+age blobs (`secrets/` outside the chezmoi source root) decrypted to 0600 files. Over SSH `op` switches to a loose service-account token. Every commit path runs `sec::leak_audit` against `.leak-patterns`. `system-onboard` reconciles a new machine end-to-end (SSH config, slot assignment, fragment build, remote `chezmoi init`+`apply` w/ normalized PATH, operator-map registration, commit/push); `--local` self-onboards. Substantial.

## G. System management
56. **`system-package` multi-ecosystem package sync** — `bin/system-package` + `system-package-{brew,cargo,go,npm,snap,uv}` + `lib/system-package-common.zsh` + `packages/{Brewfile,Cargofile,Gofile,Npmfile,Snapfile,Uvfile}.tmpl` + `Brewfile.bootstrap`. Unified declarative reconciler over 6 ecosystems (brew formulas+casks+MAS, cargo, go, npm globals, snap, `uv tool`); `list [-u] [-a]` TSV rows with parallel outdated-checks hitting registries, `sync` installs declared / uninstalls extras (strict where safe); shared engine: comment-stripping manifest reader, canonical-name tokenizer, `<name> -- <spec>` alt install form, version-diff helpers, `pkg::restart_services_for` (restarts services whose backing package was upgraded → delegates to `system-service restart-for`, only running ones). Brew worker guards mise-owned runtimes, merges bootstrap+main Brewfile. Snap worker intentionally doesn't remove undeclared (snapd auto-installs base/platform snaps). Substantial.
57. **`system-service` unified launchd + brew manager** — `bin/system-service` + `system-service-{launchd,brew}` + `packages/services.toml.tmpl`. `list`/`start`/`stop`/`restart`/`info`/`sync` over launchd user agents (TOML→plist via yq/jq, `~`-expansion + `command -v` resolution, working/log dirs auto-created) and brew services pass-through; `list` aggregates both into a normalized status table; `restart-for <pkg>…` is the hook called by package-sync (finds service by key or `cmd[0]` basename, restarts only if running). `services.toml` declares real agents: the `clipboard-bridge` socat (the SSH paste-back tunnel for #1), `images-automount`, and `mlx-gemma` (on-demand local MLX inference on :8799). Substantial.
